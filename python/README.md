# LiteCap — 极简离线录屏工具

一个从零写起的小型 Windows 录屏程序。它只做一件事：**把屏幕录成 MP4**。

设计目标完全对应最初的三条要求：

| 要求 | 实现方式 |
| --- | --- |
| **去除网络请求** | 整个程序不导入任何网络模块，源码中不存在 socket / HTTP / 更新检查 / 遥测代码。可用 `check-offline.bat` 自检。 |
| **UI 简单一些** | 单窗口、一屏内完成全部操作。没有标签页、没有向导、没有广告位、没有启动画面。 |
| **完全本地化** | 全部界面文案放在 `lang/*.json`。新增一种语言 = 新增一个 JSON 文件，不需要改一行代码。 |

## 运行

双击 **`LiteCap.bat`** 即可。

首次运行会在程序目录生成 `settings.json` 保存你的选择。

## 界面说明

```
录制区域   [全部屏幕 ▾]  [框选…]     ← 可选全部屏幕 / 单块显示器 / 自定义矩形
帧率       [30 fps ▾]
画质       [高（体积大） ▾]
界面语言   [简体中文 ▾]
保存到     [D:\Recordings]  [浏览…]
           [ ● 开始录制 ]  [ 悬浮窗 ]
```

- **框选**：点「框选…」后主窗口会隐藏，整个桌面变暗，按住鼠标拖出要录的矩形，松开即生效；按 `Esc` 取消。
- **停止**：录制中按钮变为「■ 停止录制」，点击后程序会写完文件尾部再结束，状态栏显示文件名、体积和时长。
- 输出文件名格式：`LiteCap_20261015_034512.mp4`

## 悬浮窗模式

点「悬浮窗」按钮，主窗口会收起，只留下一个置顶小条：

```
┌────────────────────────────┐
│  ● 录制    00:00     ▣     │
└────────────────────────────┘
```

- **整条可拖动**，位置会记进 `settings.json`，下次打开还在原处。
- 点 **● 录制** 立刻按当前设置开录，按钮变灰显示 **■ 停止**，中间的计时器实时走动。
- 点 **▣** 回到完整窗口（鼠标悬停有提示）。
- 录制中关闭主窗口不会丢文件，程序会先把文件尾写完。

适合「设定一次、之后随手录」的用法：先在主窗口把区域/帧率/画质调好，切到悬浮窗，之后每次只需点一下。

## 输出

- 容器/编码：**MP4 / H.264 (libx264)**，`yuv420p`，浏览器与各类播放器通吃。
- 画质档位对应 CRF：高 = 18，中 = 23，低 = 28。
- 默认输出目录：**`D:\Recordings`**（若 D 盘不存在则退回 `%USERPROFILE%\Videos`）。
- 宽高会自动裁剪为偶数，这是 H.264 的要求。

## 本地化

`lang/` 下每个 JSON 就是一个语言包：

```json
{
  "_name": "简体中文",
  "start": "● 开始录制",
  "saved": "已保存 {name}（{size}，时长 {time}）"
}
```

`_name` 是下拉框里显示的语言名，其余键对应界面文案，`{...}` 是占位符。
新增语言只需复制 `en-US.json` 改名为目标语言代码（如 `ja-JP.json`）并翻译，重启程序即可在下拉框里选到。
缺失的键会自动回退到英文，再回退到键名本身，不会出现空白。

## 自检：确认它真的不联网

双击 `check-offline.bat`，或运行：

```
python LiteCap.py --self-check
```

它会扫描源码里是否存在网络相关导入，输出：

```
LiteCap 1.0.0 — offline self-check
  source file : LiteCap.py
  network imports found: 0
  verdict: OFFLINE-ONLY (no network imports)
```

装好依赖后即可直接 `python LiteCap.py`。

## 已知边界

- **不录制声音。** 当前版本只录画面。加系统声音需要 WASAPI 环回采集，加麦克风需要额外设备枚举，都会明显增加复杂度，与「极简」相冲突，所以留给后续版本。
- **抓屏走 GDI（mss）。** 1080p@30fps 实测稳定；4K@60fps 建议先把帧率降到 30。若需要游戏级别的帧率，应换成 Windows Graphics Capture（WinRT）。
- **悬浮窗本身会被录进画面。** 这是屏幕录制绕不开的性质——它就在屏幕上。想要干净的成片，两种办法：① 录之前把悬浮窗拖到录制区域之外（配合「框选」自定义区域最好用）；② 切回主窗口操作，主窗口在录制开始后可以最小化。
- 录制中的窗口若覆盖在录制区域上，会被一起录进去——同上，这是屏幕录制的性质，不是缺陷。

## 可以继续加的东西

按实用性排序，需要哪个跟我说：

1. **全局热键**（如 `F9` 开始/停止）——有了它悬浮窗就能在录制时自动隐藏，成片更干净。
2. **系统声音 / 麦克风录制**（WASAPI）。
3. **鼠标点击高亮、按键显示**。
4. **录制时长上限 / 分段保存**。

## 与 Bandicam 的关系

本程序与 Bandicam 无任何代码或授权关系，是独立实现的替代工具。
它不读取、不修改、不依赖 `D:\Bandicam` 下的任何文件。
